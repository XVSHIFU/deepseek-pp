# 超时修复包：更新与试用

适用于已安装 `deepseek-web-harness-20260908` 的 Windows / Linux 用户。保留现有 Harness、会话和配对，只更新下面两项。没有安装过的电脑仍需先按主 README 安装完整环境。

## 1. 更新 Harness 插件

停止正在运行的 `dsh web`，进入本修复包目录。

Windows PowerShell：

```powershell
$plugin = @(Get-ChildItem -LiteralPath ./plugin -Filter '*.tgz' | Select-Object -ExpandProperty FullName)
dsh plugin --profile web add $plugin --allow-build=koffi --force
```

Linux / WSL Ubuntu：

```bash
dsh plugin --profile web add ./plugin/*.tgz --allow-build=koffi --force
```

需要 pnpm 11.7.0。命令成功后再继续；不用删除 profile 或重新配对。

## 2. 更新浏览器扩展

解压 `extensions/chrome` 或 `extensions/edge` 中的 ZIP。先备份当前加载的扩展文件夹，再将解压后的文件覆盖到原文件夹，保持原路径不变。然后在扩展管理页点击「重新加载」，刷新 DeepSeek 网页。

不要卸载原扩展、不要加载修复包根目录。Firefox 使用 `extensions/firefox` 中的对应包，沿用现有开发版加载方式。

WSL 用户仍更新 Windows 浏览器里的扩展；Harness 中执行命令不需要浏览器的 Shell Local。
