# 官方 Harness 增量插件使用说明

本地候选包包含一个不依赖源码 checkout 或私有 workspace 包的 DeepSeek Web DSH 插件、三份锁定的 Harness 请求预算归档，以及 Chrome、Edge、Firefox 的匹配扩展 ZIP。它不是公开发行版。官方公开传递依赖仍由 npm registry 解析，因此安装时需要联网；本候选不是完整离线依赖仓库。

要求：Windows、Node.js 24、DeepSeek Harness `0.1.2-rc.1`、PowerShell 7，以及已登录 DeepSeek 的受支持桌面浏览器。安装不会修改旧 standalone DeepSeek Web Agent。

## 安装

在候选包目录打开 PowerShell。先把交付记录中单独提供的 manifest SHA-256 填入 `$expectedManifestSha256`；候选目录自身的 `SHA256SUMS` 只能检查内部一致性，不能代替这个外部信任锚。核对后，通过官方 DSH 插件命令一次加入三份预算归档和插件包：

```powershell
$package = (Get-Location).Path
$expectedManifestSha256 = '<交付记录中的 manifest SHA-256>'
$actualManifestSha256 = (Get-FileHash -LiteralPath "$package\manifest.json" -Algorithm SHA256).Hash.ToLowerInvariant()
if ($actualManifestSha256 -ne $expectedManifestSha256) { throw '候选 manifest SHA-256 不匹配' }
$vendor = @(Get-ChildItem -LiteralPath "$package\vendor" -Filter '*.tgz' | Sort-Object Name | Select-Object -ExpandProperty FullName)
$plugin = @(Get-ChildItem -LiteralPath "$package\plugin" -Filter '*.tgz' | Select-Object -ExpandProperty FullName)
if ($vendor.Count -ne 3 -or $plugin.Count -ne 1) { throw '候选包数量不符合 manifest' }
dsh plugin --profile web add $vendor $plugin[0] --allow-build=koffi
```

`--allow-build=koffi` 只允许本次 profile 安装构建锁定的 `koffi@3.2.1`；它是官方 JSONL session backend 的 Windows 原子文件依赖。不要改成不限定包名的全局批准。

从 `extensions\chrome`、`extensions\edge` 或 `extensions\firefox` 选择当前浏览器对应的 ZIP，解压后以浏览器的开发者模式加载。打开 `dsh web`，在官方设置页的 DeepSeek Web 卡片填写浏览器扩展 ID，生成配对 token，并把 token 复制到扩展的 Harness 设置中。token 只显示一次，普通状态页不会回读明文。

Windows 原生命令默认关闭。需要时在同一设置卡明确启用，保持“逐条确认”，并确认 PowerShell 7 路径；自动执行是独立的显式选项，只影响启用后创建的新会话。

## 更新与卸载

更新时先在新候选目录重复 manifest、数量校验，再用同一组新候选归档强制刷新同版本的本地 file spec。`--force` 是本地候选更新所需的 pnpm 透传参数；构建批准仍只限 Koffi：

```powershell
dsh plugin --profile web add $vendor $plugin[0] --config.offline=true --force --allow-build=koffi
```

更新复用已安装 profile 的 content-addressable store，不重新联网探测可选平台包；新候选的四个输入仍来自已校验的本地 tgz。不要混用不同候选包内的插件和预算归档。命令成功退出后再启动 `dsh web`。

安全的默认卸载只移除增量插件：

```powershell
dsh plugin --profile web remove '@deepseek-pp/dsh-deepseek-web-official-plugin' --config.offline=true --force
```

这里的 `--config.offline=true --force` 与更新路径相同，用于让 pnpm 只使用安装时已有的 store 并确定性刷新本地 file spec；它不扩大卸载目标，命令仍只命名这一项增量插件。

三份预算包可能在安装前已是用户的直接 override；不要无条件删除。需要完整清理时，只能在当前 spec 仍指向本候选的前提下，把安装前存在的 spec 逐项恢复，并只删除安装前不存在的项；发现第三方已改动时应停止并人工核对。官方 `web` profile 的 base/Web 插件、其他 provider、默认模型和会话不属于该卸载目标。插件设置、credential 和历史由 DSH home 管理；删除这些数据需要另行明确操作。
