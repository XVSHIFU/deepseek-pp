# P6 本机交互入口

现在支持连续对话、退出后恢复已完成的会话，也保留单任务命令。当前为本地候选版，尚未完成全部发布验收。

环境：Windows、PowerShell 7.2+、Node.js 24，以及同一个 Chrome 中已登录的 DeepSeek 和现有 P5 新扩展。不需要 Pi 或任何模型 API key；本页不需要 Ubuntu。

在扩展“设置 → 本机 Harness”保留端口 `43123`，Ctrl+V 粘贴配对令牌并保存。之后不用每次重新配对。本轮浏览器代码未变，无需重装现有扩展。

## 2. 开始连续对话

改成你要工作的目录，再执行：

```powershell
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
node "$agentRoot\dsh-web-agent.mjs" start --workspace 'C:\你的项目目录' --mode readonly
```

保持网页登录；看到等待提示后，在一分钟内点一次扩展里的“保存”。出现 `你 >` 后，直接输入任务并回车，回答后可以继续追问。

输入 `/exit` 退出并保存会话；`Ctrl+C` 取消并退出。记下开头显示的 `session-...` 会话 ID。

## 3. 下次继续这个会话

使用相同工作目录，把会话 ID 换成刚才那一个：

```powershell
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
node "$agentRoot\dsh-web-agent.mjs" start --workspace 'C:\你的项目目录' --mode readonly --resume 'session-你的会话ID'
```

仅支持空会话或最后一轮已完成的会话。失败、中断或结果不明的会话不会自动续跑，避免重复执行工具。

## 常用选项

- `readonly`：只允许读取所选目录内的普通文件。
- `files`：允许在所选目录内编辑文件，并使用项目 Skills、摘要和串行子 Agent。**只对你允许修改的目录使用。**
- 终端命令仍须使用既定 Linux/Ubuntu 路线；Windows 不提供模型 PowerShell 执行。
- 若只做一个任务，在启动命令后加 `--task '你的任务'`，完成即退出；不要同时加 `--resume`。

`WAITING_FOR_BROWSER` 表示未连上已配对扩展：检查端口、令牌及扩展 ID，再启动并保存连接。认证错误时，先在同一浏览器网页发送一次普通对话。

日常退出用 `/exit`，无需卸载。维护命令见 [技术说明](../../packages/dsh-web-agent-bundle/README.md#fixed-local-installation-p6-development)。
