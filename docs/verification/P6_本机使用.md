# 本机 Harness 日常使用

流程：首次配置 → 命令行启动 Harness → 在官方 Harness 网页中使用。

本机现有 `0a66c3a` 安装已完成升级、配对及真实网页读取验证。日常直接启动即可，不需要重新安装、更换扩展、输入扩展 ID 或复制令牌。只有新机器首次安装、或维护者明确安排版本升级时，才使用 [首次安装与配对](P6_首次安装.md)；本次不要再执行旧的整套升级命令。

## 1. 启动并聊天

在装有配套 DeepSeek++ 的 Chrome 中，保持 DeepSeek 官网已登录、已打开。在 PowerShell 执行：

```powershell
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
node "$agentRoot\dsh-web-agent.mjs" web --workspace 'C:\Users\worker\Documents\cc-learning' --mode readonly
```

这会打开本机官方 Harness 网页。在里面选择项目、新建会话并发送任务，例如“读取 README.md，说明这个项目是做什么的”，之后直接追问。DeepSeek 官网只需保持打开，不必在那里重复发送任务。

使用其他项目时，替换命令中的绝对路径。切换项目或模式时，先停止服务，再用新参数启动。

## 2. 选择权限模式

- `readonly`：读取工作目录内的文本文件，不修改文件、不运行命令。
- `files`：允许查看、新建和修改工作目录内的文件，也可使用项目 Skill 和前台子 Agent。先确认目录和备份；无需 Ubuntu。
- `linux-commands`：另加 Bash 命令能力，必须在已配置的 Linux/WSL 运行环境中启动，不能仅在 Windows 命令后替换这个参数。详见 [Linux 环境说明](../../packages/dsh-web-agent-bundle/README.md#optional-linux-commands-including-wsl-ubuntu)。

需要编辑时，将上方命令末尾改成 `--mode files`。Windows 下读取和编辑文件均不需要 Pi、模型 API key 或 Ubuntu。

## 3. 恢复与退出

下次用相同目录和模式启动，在网页侧边栏选择已完成的历史会话继续，无需复制会话 ID。只关闭网页不会停止服务；等回答完成后，在启动它的 PowerShell 中按 `Ctrl+C` 停止。

若任务执行中要停止，先在网页取消并等待结束，再停止服务。中断或结果不明的会话可查看历史，但不会自动重放任务，也不会替你撤销已经写入的文件。

终端入口仍可用：

```powershell
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
node "$agentRoot\dsh-web-agent.mjs" start --workspace 'C:\Users\worker\Documents\cc-learning' --mode readonly
```

每行输入一个任务；`/exit` 退出，`Ctrl+C` 取消并退出。恢复终端会话时，在同一命令末尾添加 `--resume '终端此前显示的session-ID'`。

## 4. 连接不上时

自动重连通常需约 30 秒，浏览器或电脑休眠可能延迟。若仍提示 `WAITING_FOR_BROWSER`，确认扩展已启用、DeepSeek 官网已登录，必要时在扩展“设置 → 本机 Harness”点一次“保存”。不要反复重新安装或生成令牌。

安装状态检查（不会调用模型）：

```powershell
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
node "$agentRoot\dsh-web-agent.mjs" doctor
```

环境为 Windows、PowerShell 7.2+、Node.js 24.x，Harness 固定 `0.1.2-rc.1`。当前网页不开放切换模型、任意工作区设置、图片输入或会话分叉；本机 Harness 功能未发布到上游商店。验证记录见 [活动进度](../progress/MASTER.md)。
