# P6 本机入口（本地开发版）

这是日常任务入口，不是前面的随机文件测试。当前是单任务命令行入口；交互式对话／继续旧会话的界面尚未交付，也不是公开发行版。

环境：Windows、PowerShell 7.2+、Node.js 24，以及同一个 Chrome 中已登录的 DeepSeek 和现有 P5 新扩展。不需要 Pi 或任何模型 API key；本页不需要 Ubuntu。

## 1. 安装一次

在 PowerShell 整段执行，按提示填当前新版扩展 ID：

```powershell
cd 'C:\Users\worker\Documents\deepseek+++++'
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
$extensionOrigin = 'chrome-extension://' + (Read-Host '新版 DeepSeek++ 扩展 ID').Trim()
node .\scripts\install-dsh-web-agent.mjs --distribution 'C:\temp\deepseek-web-agent-dev-p6-20260906-c' --sha256 'a5d8113ac7fdf9afe008f18ef296be2078d953536f37e64ba4a49425396a84a1' --home $agentRoot --origin $extensionOrigin
if ($LASTEXITCODE -ne 0) { throw '安装未完成，请保留最后错误行' }
node "$agentRoot\dsh-web-agent.mjs" pair --copy-token
```

在扩展“设置 → 本机 Harness”保留端口 `43123`，Ctrl+V 粘贴新配对令牌并保存。之后不用每次重新配对。无需重装扩展。

## 2. 开始一个任务

将工作目录和任务改成你自己的内容：

```powershell
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
node "$agentRoot\dsh-web-agent.mjs" start --workspace 'C:\你的项目目录' --mode readonly --task '读取 README.md，概括这个项目的用途。'
```

保持网页登录。看到终端等待提示后，在一分钟内点一次扩展里的“保存”。若出现 `WAITING_FOR_BROWSER`，说明等待期间未连上已配对扩展；确认扩展 ID、端口和令牌一致，再重新启动并保存连接。任务完成后终端退出；下一个任务再运行这条命令。

- `readonly`：只允许读取所选目录内的普通文件。
- `files`：允许在所选目录内编辑文件，并使用项目 Skills、摘要和串行子 Agent。**只对你允许修改的目录使用。**
- 终端命令仍须使用既定 Linux/Ubuntu 路线；Windows 不提供模型 PowerShell 执行。

## 检查（可选）

```powershell
node "$agentRoot\dsh-web-agent.mjs" doctor
```

`doctor` 只检查本地安装，不代表网页已登录；认证错误时先在同一浏览器网页发送一次普通对话。

## 卸载（仅在不再使用时执行）

**继续使用不需要卸载，也不需要运行这一步来证明任务成功。** 先结束正在运行的任务，再执行：

```powershell
node "$agentRoot\dsh-web-agent.mjs" uninstall
```

卸载会停用本产品的活动链接，保留会话、恢复记录、配对和旧版本；不会卸载浏览器扩展或删除项目。已卸载后想恢复使用，重新执行第 1 步即可，同一分发会复用保留的安装与配对。
