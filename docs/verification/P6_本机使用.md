# 本机 Harness 网页使用

现在的流程：配置一次 → 命令行启动 → 在官方 Harness 网页聊天。模型仍是 Chrome 中已登录的 DeepSeek 网页，不需要 API key、Pi 或 Ubuntu（读取/编辑文件模式）。

环境：Windows、PowerShell 7.2+、Node.js 24。下面是**你现有安装的升级步骤**，保留配对和会话，不必再输入扩展 ID。

## 1. 本次升级，只做一次

先结束正在运行的 Harness。在 Chrome 扩展管理页暂时关闭 DeepSeek++，不要点“移除”。然后在 PowerShell 整段执行：

```powershell
cd 'C:\Users\worker\Documents\deepseek+++++'
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
node .\scripts\install-dsh-web-agent.mjs --distribution 'C:\temp\deepseek-web-agent-dev-web-0a66c3a' --sha256 'bd017c42268d69bfc22faa8a96764692ab5e990a9b533be27cd86f68dccf83f4' --home $agentRoot
if ($LASTEXITCODE -ne 0) { throw '升级未完成，请保留错误行' }

$ext = 'C:\temp\deepseek-pp-p5-5e9e641\dist\chrome-mv3'
Copy-Item -LiteralPath $ext -Destination ($ext + '.backup-' + (Get-Date -Format 'yyyyMMdd-HHmmss')) -Recurse -ErrorAction Stop
Get-ChildItem -LiteralPath 'C:\temp\deepseek-web-ui-0a66c3a-chrome\chrome-mv3' -Force | Copy-Item -Destination $ext -Recurse -Force -ErrorAction Stop
```

这里的扩展目录已核实是你当前加载的位置，ID 为 `jglphfcpedledbekoijcoiohkaobfncf`。先备份再覆盖，不删除旧目录；**不要从新路径另装一份扩展**。

回到 Chrome，重新启用 DeepSeek++ 并点“重新加载”，再刷新已登录的 DeepSeek 页面。保留“本机 Harness”中原有端口和令牌，不必重新配对。

## 2. 日常启动

保持 Chrome 中的 DeepSeek 网页已登录、已打开。执行下面命令，会自动打开**本机官方 Harness 网页**：

```powershell
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
node "$agentRoot\dsh-web-agent.mjs" web --workspace 'C:\Users\worker\Documents\cc-learning' --mode readonly
```

在本机网页新建会话，输入：**“读取 README.md，说明这个项目是做什么的。”** 回答后直接追问即可。不要把任务发到 DeepSeek 网页；那个页面保持登录，为本机 Harness 提供模型。

下次运行同一命令，在侧边栏选择已完成的历史会话继续。无需复制会话 ID，也无需每次点扩展“保存”。

## 3. 退出与常用选项

- 等当前回答完成，再回 PowerShell 按 `Ctrl+C` 停止服务；只关闭网页不会停止服务。
- 允许修改项目时，把 `--mode readonly` 换成 `--mode files`。这会允许模型编辑所选目录内的文件，请先确认工作区。
- 自动重连通常等约 30 秒；浏览器休眠可能延迟。若仍提示 `WAITING_FOR_BROWSER`，检查扩展启用和网页登录，必要时在“本机 Harness”点一次“保存”。
- 任务中途关闭或结果不明的会话可以查看历史，但不会自动续跑。终端入口 `start` 仍保留；Linux 命令路线未变。

本阶段支持网页对话、工具过程、文件读写与已完成会话恢复；不开放网页切换模型/任意工作区、图片输入或会话分叉。开发版本来源 `0a66c3a`，未发布到商店；本地验证与待完成的真实网页确认见 [活动进度](../progress/MASTER.md)。
