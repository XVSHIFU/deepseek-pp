# Harness 首次安装与配对

仅供新安装，或明确安排升级的维护者使用。**现有 `0a66c3a` 用户无需重装、更换扩展或重新配对，直接看 [日常使用](P6_本机使用.md)。**

环境：Windows、PowerShell 7.2+、Node.js **24.x**（含 npm）和 Chrome。Harness 固定为 `0.1.2-rc.1`。无需下载完整源码仓库、准备 `node_modules`、手动执行 `npm ci`、安装 Pi 或配置模型 API key。首次安装会联网下载锁定的运行依赖；读取和编辑文件不需要 Ubuntu。

本文对应本地交付包 `deepseek-web-harness-e09baf0`，不是商店发布。当前机器上的永久交付目录是 `C:\Users\worker\Documents\deepseek+++++\.release\deepseek-web-harness-e09baf0`；复制到其他机器时，可自行选择长期保留的目录。

## 1. 加载扩展

将交付包中 `extensions/chrome/deepseek-plus-plus-1.14.0-chrome.zip` 解压到一个长期保留的文件夹。打开 `chrome://extensions/`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录，记下扩展 ID。不要同时启用另一份 DeepSeek++。

用这个 Chrome 打开 DeepSeek 官网并登录。若刚加载扩展，先在官网发送一条普通消息，确认网页登录可用。

## 2. 安装本机程序并配对

在 PowerShell 整段执行。只在这里填写一次扩展 ID；交付包目录应是包含 `runtime` 文件夹的绝对目录。

```powershell
$deliveryRoot = (Read-Host '交付包所在的绝对目录').Trim()
$runtime = Join-Path $deliveryRoot 'runtime'
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
$extensionOrigin = 'chrome-extension://' + (Read-Host '刚加载的 DeepSeek++ 扩展 ID').Trim()
node "$runtime\packages\dsh-web-agent-bundle\bin\dsh-web-agent.mjs" install --distribution $runtime --sha256 'cd6009ba8d4921da40dd5a4b6054b7257cfcb1f03752a2cb9bb81d700ee59de6' --home $agentRoot --origin $extensionOrigin
if ($LASTEXITCODE -ne 0) { throw '安装未完成，请保留错误行' }
node "$agentRoot\dsh-web-agent.mjs" pair --copy-token
if ($LASTEXITCODE -ne 0) { throw '令牌复制未完成，请保留错误行' }
```

安装器先校验运行包，再安装锁定依赖；命令中的 SHA-256 对应此包的 `runtime/distribution.json`，不能用于其他构建。

令牌已复制到剪贴板。打开扩展“设置 → 本机 Harness”：启用桥接、端口填 **43123**、粘贴令牌并保存。服务尚未启动时显示“等待重试”正常。不要分享令牌。

## 3. 打开 Harness 网页

保持已登录的 DeepSeek 官网打开，执行：

```powershell
$agentRoot = Join-Path $env:LOCALAPPDATA 'DeepSeekWebAgent'
$projectPath = (Read-Host '要使用的项目绝对目录').Trim()
node "$agentRoot\dsh-web-agent.mjs" web --workspace $projectPath --mode readonly
```

在自动打开的本机 Harness 网页中发送任务，例如“读取 README.md，说明这个项目的用途”。下次只需这条启动命令；不再安装、复制 ID 或配对令牌。文件编辑、历史恢复及退出方法见 [日常使用](P6_本机使用.md)。
