# T9 本机诊断版

此版本只用于定位“流不完整”和后续会话被隔离的原因，不是完整 T9 修复或正式发布。

## 用户只需协助一次扩展更新

1. 告诉编排 agent：Chrome 扩展详情中的“加载来源”目录。
2. 诊断版构建在 `C:\Users\worker\Documents\deepseek-t9-diagnostic-20260909\chrome-mv3`。保留原扩展 ID：先备份原目录，再将该目录内容复制到原目录；不要卸载扩展或重新配对。
3. 在 Chrome 扩展管理页点击该扩展的“重新加载”，刷新已登录的 DeepSeek 网页；然后告诉 agent“已重新加载”。

浏览器工具不能操作扩展管理页，因此此步骤需要用户手动完成。安装 Harness 插件和后续真实只读测试由 agent 负责。当前运行的服务、配对和会话在用户准备好前保持原样。

## 诊断含义

新版错误中的 `reason=deepseek_stream_incomplete.v1:...` 只含 HTTP 状态、响应分类、字节数、SSE 事件数以及受限数字错误码。`json_error` 表示收到 JSON 业务错误；`sse_error` 表示流中的错误信号；`sse` 表示流没有受识别的完成标记。不能仅凭这些分类猜测上游错误码含义。

旧请求异常后出现 `reason=SESSION_QUARANTINED`，表示后续请求被隔离状态阻止，并不是又执行了一次模型任务。

不采集 Cookie、Authorization、PoW、完整提示词或原始响应正文。不要上传 HAR、凭据文件或包含令牌的地址。失败后不要反复点“继续”；agent 将保留证据后分析。
