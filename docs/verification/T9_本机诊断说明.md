## 诊断含义

新版错误中的 `reason=deepseek_stream_incomplete.v1:...` 只含 HTTP 状态、响应分类、字节数、SSE 事件数以及受限数字错误码。`json_error` 表示收到 JSON 业务错误；`sse_error` 表示流中的错误信号；`sse` 表示流没有受识别的完成标记。不能仅凭这些分类猜测上游错误码含义。

旧请求异常后出现 `reason=SESSION_QUARANTINED`，表示后续请求被隔离状态阻止，并不是又执行了一次模型任务。

不采集 Cookie、Authorization、PoW、完整提示词或原始响应正文。不要上传 HAR、凭据文件或包含令牌的地址。失败后不要反复点“继续”；agent 将保留证据后分析。
